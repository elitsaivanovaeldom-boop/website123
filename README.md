# Малки стъпки — учим с игра в 1. клас

Образователен сайт на български за първокласници с 20 кратки задачи за букви, звукови модели, срички, смятане и света около нас. Кремав фон, лавандулови, ментови и прасковени акценти и интерактивна 3D книга с цялата българска азбука.

## Локално стартиране

Използвай Node.js 24.x и npm. В основната папка на проекта:

```sh
npm ci
npm run dev
```

Отвори http://localhost:3000. Не са необходими environment variables или външни услуги.

## Проверки и production

```sh
npm run typecheck
npm run build
npm run start
```

TypeScript проверката първо генерира Next.js типовете, за да работи и след чисто изтегляне. Build компилира и предварително генерира началната страница. `start` изисква завършен build.

## Публикуване във Vercel

`vercel.json` задава изрично Next.js и командите за инсталация и build. Така публикуването не зависи от стара настройка Framework Preset: Other в проекта. Промяната влиза в сила при нов deployment; вече публикуваните версии не се променят.

1. Импортирай GitHub хранилището във Vercel: Add New → Project → Import Git Repository.
2. Framework Preset: **Next.js**; Root Directory: основната папка на хранилището (`.`).
3. Node.js: **24.x**; Install Command: `npm ci`; Build Command: `npm run build`. Остави Output Directory по подразбиране за Next.js.
4. Не са необходими secrets или environment variables. Публикувай с Deploy.
5. В Preview Deployment провери книгата, завъртането с мишка и разлистването с touch, всички секции, мобилния изглед и системната настройка за намалено движение.

Lockfile фиксира зависимостите. PostCSS override прилага поправките за известните уязвимости, включително към вложеното копие в Next.js 15. 3D книгата и текстурите на страниците се генерират локално, включително българските букви. Няма външни ресурси за зареждане.

## Браузърни тестове

След `npm run build`:

```sh
npx playwright install chromium
npm run test:e2e
```

Playwright стартира production сървър на порт 3100. Ако използваш системен Chromium, задай `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` към неговия изпълним файл. Тестовете проверяват всички учебни режими, подсказките, завършването, рестартирането, клавиатурната навигация, мобилните ширини, завъртането на книгата с мишка, всичките 30 букви и разлистването с бутони и touch. Външните заявки са блокирани по време на тестовете.

## Учебни игри

Всеки режим съдържа четири задачи с обратна връзка и възможност за повторен опит. В „Букви и думи“ има отделни режими „Букви“, „Звукови модели“ и „Срички“. Гласните са обозначени с червени квадратчета и Г, съгласните - със сини квадратчета и С. Използвани са думи с еднозначно съответствие между букви и звукове, без автоматично приравняване на буквите към звукове. След верен отговор се показва звуковият модел с буквите или думата, разделена на срички. След завършване може да се избере друга тема или играта да започне отново. Напредъкът е само за текущата игра и не се запазва след презареждане. Няма регистрация, събиране на лични данни или външни услуги за задачите.

Книгата съдържа всички 30 български букви в 15 разтвора с примерни думи. Движението на мишката я завърта леко, като буквите остават четими. Страниците се разлистват с бутоните, стрелките на клавиатурата, клик от двете страни на книгата или хоризонтално плъзгане. Вертикалното скролиране на телефон е запазено. При намалено движение страниците се сменят веднага, а автоматичното плаване е изключено. Ь е представен като знак за мекост. Игрите са за допълнително упражнение с подкрепата на родител или учител.
