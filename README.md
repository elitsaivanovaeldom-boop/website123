# Малки стъпки - учим с игра в 1. клас

Образователен сайт на български за първокласници с 20 кратки задачи за букви, звукови модели, срички, смятане и света около нас. Кремав фон, лавандулови, ментови и прасковени акценти и анимиран 3D молив, който изписва ръкописни букви и рисува картинки.

## Локално стартиране

Използвай Node.js 24.x и npm. В основната папка на проекта:

```sh
npm ci
npm run dev
```

Отвори http://localhost:3000. Не са необходими environment variables или външни услуги.

## Проверки и production

```sh
npm run typecheck
npm run build
npm run start
```

TypeScript проверката първо генерира Next.js типовете, за да работи и след чисто изтегляне. Build компилира и предварително генерира началната страница. `start` изисква завършен build.

## Публикуване във Vercel

`vercel.json` задава изрично Next.js и командите за инсталация и build. Така публикуването не зависи от стара настройка Framework Preset: Other в проекта. Промяната влиза в сила при нов deployment; вече публикуваните версии не се променят.

1. Импортирай GitHub хранилището във Vercel: Add New → Project → Import Git Repository.
2. Framework Preset: **Next.js**; Root Directory: основната папка на хранилището (`.`).
3. Node.js: **24.x**; Install Command: `npm ci`; Build Command: `npm run build`. Остави Output Directory по подразбиране за Next.js.
4. Не са необходими secrets или environment variables. Публикувай с Deploy.
5. В Preview Deployment провери молива, движението с мишка и автоматичното рисуване на телефон, всички секции, мобилния изглед и системната настройка за намалено движение.

Lockfile фиксира зависимостите. PostCSS override прилага поправките за известните уязвимости, включително към вложеното копие в Next.js 15. Моливът, ръкописните линии и рисунките се генерират локално. Няма външни ресурси за зареждане.

## Браузърни тестове

След `npm run build`:

```sh
npx playwright install chromium
npm run test:e2e
```

Playwright стартира production сървър на порт 3100. Ако използваш системен Chromium, задай `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` към неговия изпълним файл. Тестовете проверяват всички учебни режими, подсказките, завършването, рестартирането, клавиатурната навигация, мобилните ширини, движението с мишка, автоматичното рисуване, паузата и статичния режим. Външните заявки са блокирани по време на тестовете.

## Учебни игри

Всеки режим съдържа четири задачи с обратна връзка и възможност за повторен опит. В „Букви и думи“ има отделни режими „Букви“, „Звукови модели“ и „Срички“. Гласните са обозначени с червени квадратчета и Г, съгласните - със сини квадратчета и С. Използвани са думи с еднозначно съответствие между букви и звукове, без автоматично приравняване на буквите към звукове. След верен отговор се показва звуковият модел с буквите или думата, разделена на срички. След завършване може да се избере друга тема или играта да започне отново. Напредъкът е само за текущата игра и не се запазва след презареждане. Няма регистрация, събиране на лични данни или външни услуги за задачите.

Моливът сам изписва главна и малка ръкописна буква по предварително зададени криви. Върхът му следва действителната линия, след което се появява печатният вариант и се рисува предмет с тази буква: А - автобус, Б - балон. Двете сцени се сменят автоматично. Движението на мишката леко накланя цялата сцена. На телефон не е нужно кликване, а вертикалното скролиране и увеличаването с два пръста са запазени.

Бутонът „Пауза“ е по избор. Анимацията спира извън видимата част на страницата и в неактивен таб. При предпочитание за намалено движение се показва завършена неподвижна рисунка. Ако WebGL не е достъпен, има SVG вариант с буквата и картинката. Няма външни модели, шрифтове или графични ресурси за зареждане. Игрите за звукови модели и срички остават достъпни.
