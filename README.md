# Interactive 3D Website

Оригинална начална страница с Next.js, TypeScript, Tailwind CSS, Three.js, React Three Fiber и Motion.

## Локално стартиране

1. Инсталирай Node.js 20+.
2. В папката на проекта изпълни `npm install`.
3. Стартирай `npm run dev` и отвори http://localhost:3000.
4. Провери с `npm run typecheck` и `npm run build`.

## Публикуване във Vercel

1. Качи файловете в GitHub repository (без `node_modules` и `.next`).
2. Във Vercel избери Add New > Project > Import Git Repository.
3. Избери repository и натисни Deploy. Next.js се разпознава автоматично.

## Бележки

3D обектът е оригинална процедурна геометрия от torus knots, а не копие на чужд модел. Поддържа мишка и drag на touch устройства. При предпочитание за намалено движение анимацията се изключва. Сменете демонстрационното име и контактния текст преди публично използване.
